# Contributing to Slickk-OS
Open or claim a task from tasks/pilot.json and ensure dependencies are DONE. Create one task branch and draft PR. Attach the task ID, purpose, relevant AOSP version/commit, changed paths, before/after tests, security/license review and rollback steps.
Do not push engineering changes to main; untested code belongs only in a clearly labeled draft. Do not relicense imported AOSP/kernel code incorrectly. Never upload copyrighted proprietary device firmware or credentials.
An accepted PR requires code review, appropriate CI, test evidence and explicit owner approval to merge. If no test environment exists, accurately classify UNTESTED and do not mark the task DONE.
