# Device Policy
The current Samsung SM-A165F may be used for **read-only** inspection and APK/launcher tests with consent. Compatibility with an unlockable bootloader, custom recovery, GSI or full Slickk-OS image is NOT VERIFIED.
No flashing, bootloader unlock, partition write, firmware replacement, wipe or device-security bypass by default. Require documented supported device model, user consent, backup+restore verification, official hardware documentation and recovery medium.
The first complete OS boots on Cuttlefish. Hardware targets are chosen by evidence, not by wishful naming.
